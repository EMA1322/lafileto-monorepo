## Estado de los documentos

- **CANONICAL**: contrato o decisión normativa vigente.
- **CURRENT**: snapshot o guía operativa contrastada con el repositorio.
- **NEEDS REVIEW**: conserva valor, pero requiere nueva verificación antes de gobernar una decisión.
- **HISTORICAL**: trazabilidad de una fase concluida; no norma el trabajo nuevo.

Los documentos históricos se conservan en sus ubicaciones para no romper enlaces. Los identificados como históricos incluyen [baseline de migración Admin](03-arquitectura/admin-react-migration-contract-baseline.md), [evaluación de migración Admin](03-arquitectura/admin-react-migration-evaluation.md), [cierre Fase 0 Client](04-ux-ui/client-redesign-fase-0-cierre-y-plan.md), [contrato de lista Admin](04-ux-ui/admin-list-contract.md), [debug de login](05-procesos/debug-login.md), [UI kit](07-anexos/ui-kit.md) y [Admin UI](admin-ui.md).

Las carpetas de visión, requisitos, procesos y anexos contienen además material de referencia que debe contrastarse con estas fuentes antes de usarlo como norma.
